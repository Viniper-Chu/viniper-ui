# 本机文件 helpers 来源

`docx_local_edit.py` 与 `sqlite_local_ops.py` 来自本机模型工程提交 `eb52791`（2026-10-14），按文件内容核对后冻结用于打包。两者仅依赖 Python 标准库，不导入 Hermes、不启动或复制模型。

原件位于独立的本地模型工程 `开发维护/scripts`。更新时应读取上游的资格验收结论，再同步源码并验证 Harness 包装。源码提交与模型资格验收是不同状态。

`dispatch.py` 是 Viniper 自己的 JSON stdin 入口。DOCX 保留非目标部件；SQLite 回读发生在各事务结束后，不提供事务内条件提交接口。
