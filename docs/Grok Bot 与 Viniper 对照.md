# Grok Bot 与 Viniper 的功能对照

2026-11-17。对照基线为公开的 Viniper 2.2.2。右栏说明本机整合后的行为。比较以高中数学解答、复核和师生稿交付为目标，依据功能文档、公开仓库和本机实现。时间开销仅作机制比较，本轮没有测量两款产品的相对速度。

| 维度 | Grok Bot 或开源参考的做法 | Viniper 2.2.2 的基础与差距 | 本机选择与取舍 |
|---|---|---|---|
| 提问变成流程 | 成功的任务可以提炼为可复用的 skill [1] | 可选、可改既有技能，从会话保存自己的流程缺少入口 | **新增**。在提问旁点书本，可改写名称、适用场景和步骤再保存。初稿取自点选的提问，由使用者删除一次性题干、提炼出通用方法。 |
| 私有技能的归属 | 个人技能库与团队发布分开 [1] | 可见安装内置、本机和项目来源，用户须自行整理文件 | **新增**。Viniper 将自建技能存入自身数据目录，多个会话可用。重名会保留原文。内置技能与个人副本各有归属。 |
| 技能对模型的作用 | 小文件说明触发条件、原始证据、验收和交付 [2] | 已有按需选择和指令注入，直接键入技能命令时可能用到不同目录 | **改进**。点击选择与斜杠命令均按当前工作目录解析。被选中的正文随本轮请求交给模型。 |
| 一份工作重复执行 | 原提问可保存，也可成为有时间规则的 routine [1][3] | 已有 Cron、新建表单与会话目标，但要重新输入任务 | **新增**。提问菜单可打开预填草稿，编辑时间并点击创建后生效。只复用文字，需重复读取的题源应在草稿中指明。 |
| 快速查找 | 可在统一入口搜不同类型的工作对象 [4] | 能搜页面、会话、设置字段；技能与任务要逐页查 | **扩展**。输入关键词后读取技能、插件、目标、定时任务，点击结果进入详情。插件支持工具 ID，来自当前工作目录的技能参与匹配。各目录独立返回。 |
| 日期与时区 | OpenMausBot 展示时区和后续三次触发时间 [3] | 调度器已有预报，桌面只显示最近一次 | **接通已有数据**。定时任务详情可展开接下来最多三次触发，使用任务自身时区。暂停后撤下预报。 |
| 计划与实际执行 | 例程同时有日程和运行记录，可回到聊天查看结果 [1][3] | 后端已有历史，桌面只显示一条摘要 | **接通已有数据**。详情显示这项任务在运行时最近 50 条全局调度事件中留下的记录，区分已派发、派发失败与离线跳过。完整解题结果仍在会话。 |
| 复核方法 | research-review 要求回到原始材料判断结论 [2] | 有二次函数精确工具和编译器，缺少从技能目录直接进入的通用解答复核流程 | **新增「数学解答复核」**。以原题条件、独立推导、代回和反例找首个错步。对参数题逐支验算，工具输入须与原题等价。 |
| 运行可见性 | 开源实现将聊天、活动及定时工作关联 [3][5] | 对话已经按时间排列思考、工具、回复，侧栏和输入框指示真实运行状态 | **沿用**。一次复核仍出现在原会话，过程默认折叠，可展开查看。只有真实调度事件进入任务记录。 |
| 交付物与阅读 | 官方设计将可继续使用的文件与聊天区分 [6] | 生成文件可直接打开、定位，数学公式与师生 PDF 有专门入口 | **沿用数学交付**。检索会话目录即可返回原题和已交付文件，数学技能区分手工验算、工具回执与已编译成品。 |
| 前后端职责 | make-bot-ui 用按钮表达有限动作，实际操作与密钥留在服务端 [7] | 原生桌面已有应用端口、主机凭据与单个运行时 | **沿用并补齐**。新增按钮走现有应用接口，预报和记录来自调度器。两台设备之间的时区与休眠策略不靠前端推测。 |
| 专业分工 | Grok Bot 与 OpenMausBot 以多个持续工作的助手分工 [5][6] | Viniper 产品是单一数学 Agent，共享当前题目的附件、工作目录和状态 | **接入数学讨论组**。解题与复核分别调用模型、共用本组上下文，可点名。独立文字题可选择本地 Qwen 和 DeepSeek Flash 同时作答，只有本轮题目进入云端。 |
| 离线与后台工作 | 托管例程可在用户电脑关机时继续；开源替代也提供远端工作环境 [1][5] | 本机模型和题库依赖此 Mac，应用离线时跳过到期触发 | **保留本地执行**。预报表示计划时间，派发记录说明实际发生了什么。云端常驻需要另一套运行与数据托管方案。 |
| 外部接入与审批 | 社区桌面控制 skill 用于已有 Grok 账号和 Bot，会话可由外部工具操作 [8] | Viniper 自带目录、运行、暂停、权限确认与本机安全存储 | **保留本机权限边界**。自建技能只增加说明文本。新流程继续使用已经注册的工具和原有审批。 |
| 触发与连接器 | Grok 支持定时和部分外部事件触发 [1][7] | 内置调度当前支持本机时间规则，已授权的数据按需读取 | **采用本地时间规则**。工作台适合“每周复核错题”，外部 webhook、共享云电脑和团队发布没有接入此次构建。 |

## 桌面界面实测

以 xAI 的 1024 × 768 桌面交互示例为标尺。表中 Grok 的数值取自示例组件缩放前的布局；官网文章中的演示和后续产品更新有不同的侧栏入口。圆形搜索与新建采用较新的官方更新，Viniper 数值是本机同尺寸窗口的 CSS 像素。[官方设计示例](https://x.ai/news/designing-grok-bot) · [官方交互更新](https://x.ai/changelog/bot)

| 元件 | Grok Bot 参考 | 改版前 | 采用或适配 |
|---|---|---|---|
| 侧栏 | 280 px；会话列表在上、插件在底部 | 224 px；页面入口排在历史之前 | 桌面 280 px，会话优先；紧凑窗口自动收起 |
| 顶栏 | 44 px，名称打开详情 | 56 px，名称只展示文本 | 44 px；点击名称打开本会话的提问与文件 |
| 会话索引 | 标题 14/20 px，预览 13/18 px，行圆角 10 px，内边距 8 px | 标题 13 px，单行 | 两行采用相同字号与行高；空会话只显示名称，运行时显示真实阶段 |
| 新建、搜索 | 更新后的两个圆形顶部入口 | 两个独占一行的按钮 | 并排 28 px 按钮，保留快捷键、悬浮提示和可访问名称 |
| 输入与发送 | 单行框高 44 px，附件和发送 28 px | 附件和发送 32 px，讨论组输入区 129 px | 普通单行 44 px，发送与附件 28 px；讨论成员、多行题干和附件按内容增高 |
| 消息与长公式 | 示例短消息内边距 8/12 px、圆角 16 px、最大宽度 300 px | 提问内边距 12/16 px、圆角 12 px | 提问沿用示例间距与 16 px 圆角；数学答复可用整列，公式和表格局部滚动 |
| 详情与交付 | 示例右侧面板宽 320 px；Claude 将产物放在会话旁 | 会话目录与全局搜索共用居中弹窗 | 目录在右侧 320 px 面板内搜索、跳题与打开交付文件；全局搜索继续居中 |
| 品牌与主题 | 从中性表面、头像及运行状态区分层级 | 深青底应用图标、绿灰色画布 | 白底折面 V；浅色使用白与雾灰，深色使用炭灰，青绿色用于运行状态与链接 |

交付文件复用应用中真实的文件操作。Claude 的并排产物用于确定入口层级，打开 PDF 和源码仍使用本机应用。[Claude 官方产物说明](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them)

## 二级页面与下一级操作

| 页面 | Grok Bot 的依据 | Viniper 的具体取舍 |
|---|---|---|
| 技能与插件目录 | Connect apps 可搜索，能从目录进入已安装项并查阅工具能力 | 本机注册项目在一列中展示，插件行直接给出工具数量；待配置项显示状态。进入插件后可按名称或工具 ID 搜索，显示匹配数。 |
| 技能详情与编辑 | 私有技能可从管理目录进入，针对该项的操作放在详情标题区域 | 在标题旁使用技能或编辑可写说明。编辑页可切换源码与公式预览，保存沿用后端的原文冲突检查。 |
| 定时任务列表 | 桌面示例的例程行使用两行 18 px 行高，上下各 6 px、左右各 8 px；官方操作说明支持行内开关 | 1024 × 768 窗口实测，任务行由 61 px 改为 48 px。一击暂停或恢复，开关按调度器回读的状态显示。 |
| 目标、任务详情与编辑 | 例程详情将指令、触发时间与管理操作分区；官方另提供运行历史 | 先读状态、周期与任务内容，再查派发记录；最近三条直接显示，更早的可展开。编辑与删除放在末尾，删除确认包含条目名称。目标详情展示实际进展和轮次。 |
| 应用设置 | Grok 以功能分区管理本机和共享设置，应用连接另有目录 | 保留模型、外观、工作目录与协作规则四页。模型页区分服务参数与密钥；目录选择在路径输入旁，修改后的保存区在滚动时可用。 |
| 会话目录与跨页返回 | 详情和 Library 将会话上下文与成果分开 | 右侧目录可筛选提问或交付文件；全局查找独立。目录、详情、编辑每一级只有一个顶栏返回入口，退出编辑后恢复原条目和列表位置。 |

例程尺寸来自 xAI 公开桌面示例的未缩放布局。公式预览和本机文件入口是数学工作流的适配。派发状态仅说明本机调度器的回执。[设计示例](https://x.ai/news/designing-grok-bot) · [技能与例程管理](https://docs.x.ai/grok-bot/skills-routines-and-automations) · [连接应用](https://docs.x.ai/grok-bot/computer-and-apps) · [设置分区](https://docs.x.ai/grok-bot/settings-and-notifications)


## 3.0.0 实现范围

| 产品能力 | Viniper 的实际边界 |
|---|---|
| 分工、状态与接续 | 本地成员顺序解题、复核；显式选择双模型时独立作答。侧栏与输入区展示真实运行事件，支持引导和取消。 |
| 模型连接 | 普通会话可使用本机 Qwen 或 DeepSeek 云端工具会话，共用同一应用端口。双模型独立意见只提交当前文字题，普通云端会话包含当前上下文。凭据留在主机。 |
| 工具、检索与数学交付 | 已注册的 MCP 和技能可从目录查阅。关键词搜索和网页读取是不同工具。数学实根核验、师生稿编译及 PDF 检查通过实际工具交付。 |
| 例程与工作目录 | 使用本地时区与真实派发记录；这台 Mac 运行时执行。Grok 的托管云电脑、关机后常驻、多用户团队共享、语音通话和计费系统均不在本机实现范围。 |
| 设计参考与交互 | Grok 的侧栏、例程与连接管理是主参考，Claude 的产物分区作为补充；首页借鉴 DeepSeek 官网将互动置于背景的方式。对数指数函数的像素点阵、数值交点与指针局部放大由 Viniper 在本地绘制，支持触控和键盘。 |

对照依据为公开产品界面与行为文档，无法从中审计 Grok 私有后端的实现。[Grok Bot 概览](https://docs.x.ai/grok-bot/overview) · [DeepSeek 官网](https://www.deepseek.com/)
