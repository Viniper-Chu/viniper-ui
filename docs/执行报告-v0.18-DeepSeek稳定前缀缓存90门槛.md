## 根因与修复

旧实现每轮把 assistant 自动会话记忆再次写进下一轮 system/project header，导致请求从第 0 个 token 起变化。修复后：

1. Provider history 只追加；自动会话记忆仍可在记忆中心查看，但不重复注入 system header。
2. 用户显式记忆继续可注入，并在真实变更时开启新缓存代际。
3. 工具、Skill 和 JSON schema 使用 canonical 顺序，插件发现时序不再制造无意义前缀变化。
4. DeepSeek 工具回放与 reasoning 字段差异留在 OpenAI Chat 适配器。
5. V4 长会话在接近上下文容量前保持追加式历史；不裁短编程、网页或 Git 输出换取命中率。
