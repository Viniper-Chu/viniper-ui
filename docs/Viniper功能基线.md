# Viniper v5.0.2 功能基线

本清单是 Agent Desktop 的最终 A 基线。它来自正在运行的 Viniper 界面、README、桌面壳、API 路由、DOM 与测试入口交叉核对。前端可以优化，但这些能力不得无声消失。

范围变更：用户于 2026-08-12 明确取消独立 Chat 模式。Viniper 的普通对话体验保留在 Agent 会话中，Chat/Agent 模式切换本身不再是 MUST；除此之外的 Viniper 功能仍为最终 MUST。

## 工作区与会话

- 单一 Agent 工作区；既可普通问答，也可按权限运行工具和本地任务。
- 多会话创建、切换、恢复、搜索、重命名、置顶、未读、删除和最近会话分组。
- Agent 会话独立工作目录、上下文、消息、队列、权限、运行状态和交互请求。
- 后退/前进、侧栏展开收起与拖动、全局菜单、全局搜索、窄窗适配。

## 对话与 Agent 执行

- 流式助手回复、思考/执行过程、工具开始与结果、图片与本地产物卡片。
- Enter 发送或排队，Ctrl+Enter 引导当前任务，Shift+Enter 换行。
- 任务队列的添加、编辑、删除；运行中取消；失败后可恢复。
- AskUserQuestion 多题/多选/其他答案与工具权限允许、拒绝、恢复。
- 模型选择、权限模式、会话间消息能力、Agent 运行视图。
- 上下文真实用量、使用来源、自动压缩状态；每日用量视图。
- 文件选择、拖放附件、安全的本地产物打开和定位。

## 自定义、设置与运行时

- 本地技能搜索、分类、详情、命令插入和可用性/冲突状态。
- 用户级 Agent 指令编辑，并清楚展示指令作用范围。
- Provider 名称、地址、模型、凭据环境变量、自定义命令和环境配置。
- 默认目录、默认模型、默认权限、主题、字号、强调色、语言和本地资料。
- 运行时状态、安装/恢复、更新、诊断、自检与桌面快捷方式。
- 应用更新检查、更新说明、安装与失败反馈。

## 桌面原生能力

- Electron 原生窗口、启动画面、单实例、关闭到托盘、托盘未读提示。
- 显示/隐藏、置顶聊天窗口、浏览器打开、设置、自检、数据目录和退出。
- Windows 与 macOS 标题栏差异、数据目录隔离、正式/Preview Profile、更新不清空用户数据。

## Agent Desktop 的必要优化

- Windows 不再依赖 WSL2 或 Claude Code，改为项目自有的 Windows 原生 Agent Runtime。
- Provider 不是单一 Anthropic-compatible 配置，而是原生 OpenAI、Anthropic、Gemini 与 OpenAI-compatible 等适配器。
- 新增稳定前缀缓存规划、缓存命中可解释指标和 Provider 能力探测。
- 默认界面保持 Viniper 的安静、留白和少按钮，但用一条低饱和蓝绿色状态轨道区分空闲、执行、等待用户和系统状态。
- 高级设置保持可搜索且渐进披露，首次使用只要求“选择 Provider -> 填密钥 -> 选择模型 -> 开始”。

## 第一阶段状态

第一阶段只要求一个真实可运行的纵切：原生桌面壳、单一 Agent 会话主线、Demo Provider 流式事件、只读 Demo 工具、队列/取消的最小闭环、Provider 与缓存合同、基础设置和关键页面。其余条目仍是后续 MUST，不因第一阶段 Demo 而变成可选项。
