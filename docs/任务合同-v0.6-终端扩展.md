# 任务合同：Phase 3 原生终端扩展 v0.6

发布对象：固定执行层会话 `019ff484-a092-7322-a847-a69de0e58240` 及其按用户明确要求创建的一个 CLI 子 Agent。

本合同追加到 `docs/任务合同-v0.4.md` 与 `docs/任务合同-v0.5-视觉扩展.md`，不替代或降低其中任何 Provider、工具循环、桌面视觉、安全、测试、Windows 真窗口和公网调用为 0 的要求。版本仍为 `v0.0.1 Preview（预览版内部更新）`。

## 用户决策

- 桌面端继续是独立 Agent Harness，不得改造成“终端套壳”或依赖 Claude Code、Codex、Hermes 作为运行内核。
- 新增一个原生终端入口，与 Electron 桌面端共享本项目自己的 `core / features` Harness 能力。
- 用户明确要求执行层开启一个子 Agent 尝试 CLI；子 Agent 必须由固定执行层创建和管理，不得替换固定执行层任务。
- Windows 本阶段真实运行；macOS 同步更新草案但保持 `UNPROVEN`。

## 架构合同

```text
core + features（唯一 Harness 内核）
├─ platform/desktop + renderer（Electron 桌面适配器）
└─ platform/cli（原生终端适配器）
```

- CLI 只能调用正式应用服务/端口，不能复制会话、队列、Provider、权限、工具循环、协作、Token、定时任务或 Skills 的业务状态机。
- CLI 不启动 Electron、不抓取桌面 DOM，也不通过自动化操纵桌面端。
- 第一版使用 Node.js 原生终端能力，不新增大型 TUI 框架；输出必须能在 Windows PowerShell/Windows Terminal 原生运行。
- 为避免两个进程同时改写 JSON，v0.0.1 Preview 的 CLI 默认使用独立 Preview 数据根；若用户显式指定桌面数据根但发现另一实例活动，必须拒绝双写并给出人话提示。后续可通过本地守护进程/IPC 实现桌面与 CLI 实时共享，但不在本合同内伪造。

## 子 Agent 所有权

CLI 子 Agent 独占：

- `src/platform/cli/**`
- `tests/cli/**`
- CLI 专属复现说明或样例（进入 `codex/工作输出/cli-preview/**`）

CLI 子 Agent不得：

- 修改 `src/features/providers/**`、`src/renderer/**` 或当前执行层正在编辑的协议/界面文件；
- 回滚、清理或提交其他 Agent 的工作树变动；
- 发起公网 Provider 请求、读取用户粘贴过的 Key、安装 Agent 框架或发布远端；
- 自行修改共享 `package.json`、桌面 bootstrap 或 Git 历史。需要的集成点以清单交回固定执行层，由固定执行层在当前切片提交后完成。

## CLI 最小可用闭环

CLI 采用交互式 Agent 命令台；普通非斜杠输入直接交给当前 Agent 会话。首轮至少支持：

- `--help` / `/help`：新手友好帮助。
- `/new [名称]`、`/sessions`、`/use <会话>`、`/rename <名称>`：独立多会话。
- 普通文本或 `/run <任务>`：在当前会话执行 Agent 任务；显示流式正文、人话执行阶段、工具状态与最终状态。
- `/cancel`：只取消当前会话。
- `/tokens`：显示当前运行估算与 Provider 最终 usage；二者不得混称。
- `/inbox`、`/send <目标> <消息>`、`/delegate <目标> <任务>`、`/wait [来源]`：显式跨会话协作。
- `/schedules`、`/skills`、`/providers`：只读列出当前定义和状态；低频编辑可暂留桌面端，但须明确提示。
- `/provider <profile> <model>`：选择已经配置好的 Provider/model；CLI 不回显秘密。
- `/quit` / Ctrl+C：运行空闲时退出；运行中第一次 Ctrl+C 取消当前运行，再次才退出。

不要求首轮构建全屏 TUI、鼠标交互、ANSI 动画或在终端内复制桌面布局。核心目标是可脚本化、可键盘操作、信息明确、与 Harness 语义一致。

## 非交互入口

至少预留并测试一个可脚本化命令：

```powershell
npm run --silent cli -- run --prompt "整理当前任务" --json
```

- `--json` 逐行输出稳定事件对象，供脚本/CI 消费；不得混入装饰字符。机器消费必须使用 `npm run --silent cli -- ... --json`，避免 npm script banner 污染 JSONL；普通人类模式仍可使用 `npm run cli -- ...`。
- 人类模式可用简洁中文和有限 ANSI；检测到非 TTY 时自动关闭颜色。
- 非交互模式必须用退出码区分完成、用户取消、配置缺失与运行失败。
- 通过 npm 显式指定数据根时使用 `--data-root=<目录>`；CLI 同时识别 npm 的 `npm_config_data_root` 传递方式，并继续执行单写者检查。

## 验收

- CLI 控制器/解析器单测覆盖命令、会话切换、协作、Token、取消、JSONL 与退出码。
- 使用独立临时数据根真实启动 Windows 终端 CLI，完成至少两个隔离会话、一个本地 Demo 任务、一次跨会话消息、Token 展示和取消。
- CLI 与桌面端均调用同一正式 Harness 服务，不能用假静态输出冒充闭环。
- 完整 `typecheck / build / tests` 通过；桌面 v0.5 视觉与既有能力不得回归。
- CLI 真实运行时公网 Provider 请求为 0；真实 API、macOS 终端、安装器命令与桌面/CLI 同时共享数据仍为 `UNPROVEN`。
- 固定执行层负责集成、逻辑提交、Windows CLI 复现证据和 Phase 3 报告；子 Agent 只交付其所有权目录与集成清单。
