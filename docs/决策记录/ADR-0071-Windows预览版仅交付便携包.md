# ADR-0071：Windows 预览版当前只交付便携包

- 状态：Accepted
- 日期：2026-08-13
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

安装器能提供开始菜单、卸载和更新集成，但会提前引入注册表、安装权限、升级迁移和卸载保护问题。便携包更适合当前频繁迭代的 Preview。用户选择方案 A：Windows 当前只做便携交付。

## 决策

- Windows 当前交付物为可解压运行的 x64 便携目录及其压缩包，不生成 MSI、MSIX、NSIS、Squirrel 或其他安装器。
- 便携包不得写注册表、创建桌面/开始菜单快捷方式、安装服务、计划任务或开机启动项。
- 应用数据继续进入明确的用户数据根，不把会话、凭据或运行状态写回便携程序目录；测试必须使用隔离数据根。
- 打包必须走仓库内可复现脚本，并从解压后的最终包直接启动验证，不能只运行源码或 `node_modules` 中的 Electron。
- 自动更新的长期设计继续保留，但当前便携 Preview 不得宣称已具备安装器级原地更新能力。

## 收益

- 用户可以直接解压体验，失败时删除便携目录即可回退程序文件。
- 避免在产品尚未稳定时扩大系统安装和卸载影响面。

## 代价

- 暂无系统级安装、卸载入口、文件关联和自动创建快捷方式。
- 更新暂时需要下载新便携包并由用户替换程序目录，数据迁移仍须单独验证。

## 与既有决策的关系

- 不改变产品版本 `0.0.1` 和 Preview 阶段；未来是否新增安装器须另立决策。
