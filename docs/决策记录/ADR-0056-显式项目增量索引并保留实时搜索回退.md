# ADR-0056：显式项目增量索引并保留实时搜索回退

- 状态：Accepted
- 日期：2026-08-13
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

每次都直接扫描文件最简单，但大型项目会反复消耗时间；后台扫描整台电脑虽然搜索快，却扩大了读取范围、资源占用和隐私边界。用户选择方案 C：只为用户明确打开或加入 Viniper 的项目建立本地增量索引，索引不可用或结果可能过时时退回当前文件系统实时搜索。

## 决策

### 只索引显式项目

- 只有用户明确打开、固定或加入项目列表的规范项目根可以建立索引；不扫描其他磁盘、用户目录、相邻仓库或未选中的项目。
- 初次加入项目时读取路径、可搜索文本和可提取的符号信息；遵守项目排除规则、版本控制忽略规则和用户自定义排除项，不读取 `.git` 内部数据、已排除依赖目录或二进制正文。
- 项目完全访问和电脑完全访问不自动扩大索引范围；增加另一个项目必须是独立、可见的用户动作或当前任务明确选择。

### 增量更新与实时补查并存

- 首次索引后通过平台文件监听和已登记的文件变更事件增量更新；监听中断、项目离线或状态不确定时显示 `stale`，不能把旧索引冒充当前文件事实。
- 搜索时优先使用当前索引；新文件、未索引文件、状态不确定范围或索引服务失败时，使用同一项目根内的实时文件搜索补查并合并结果。
- 实时补查只读取本次查询需要的项目范围，不触发全盘重建；界面可以显示“索引结果”和“实时补查”来源，但普通用户不需要理解底层命令。
- 索引重建不得阻塞文件读取、编辑或 Agent 运行；搜索可以降级为实时模式并如实显示速度状态。

### 本地存储与模型边界

- 索引正文、符号表和辅助缓存只保存于本机受管数据根，SQLite 保存项目、版本、状态和文件引用；renderer 不直接打开索引数据库。
- 索引属于 ADR-0052 的可再生成产物，可以按用户选择的周期清理；清理索引只删除受管缓存，不删除或改写项目文件，需要时重新建立。
- 不把完整索引上传给任何 Provider。Agent 只能通过项目搜索工具取得与当前任务相关的有界结果，再按当前 Provider/权限合同使用。
- 预览版以路径、文本和符号检索为主，不把向量数据库或全盘语义索引作为编程能力前置条件。

## 产品表现

- 项目页显示“正在建立索引 / 已就绪 / 需要刷新 / 使用实时搜索”四类普通状态，并提供手动重建和暂停索引入口。
- 搜索结果统一展示文件、位置和匹配摘要，不要求用户在两套搜索页面之间切换。
- 大项目首次建立索引时仍可立即工作；暂未索引到的内容由实时搜索补足。

## 收益

- 大项目的重复搜索更快，同时不会扫描整台电脑。
- 文件监听或索引失败时仍能继续完成编程任务。
- 索引可删除重建，不会成为新的正式数据真源。

## 代价

- 需要维护索引状态、平台文件监听和结果去重。
- 首次索引会占用一定 CPU、磁盘和时间。
- 实时补查时搜索速度可能暂时下降。

## 与既有决策的关系

- 实现 ADR-0026 的 P1 项目发现、搜索和读取目标，并遵守 ADR-0027 的规范项目边界。
- 索引缓存按 ADR-0032/0052 进入受管文件与可再生成生命周期，不改变项目文件真源。
- ADR-0066 在本 ADR 的基础词法/符号能力之上增加按项目可选的本地语义层；ADR-0067 细化基础与语义索引的低优先级资源调度，两者都不能取消实时回退。
- 本 ADR 是后续目标设计；增量监听、实时回退、大项目性能和 Windows/macOS 真机行为均为 `UNPROVEN`。
