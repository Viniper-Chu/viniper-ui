# ADR-0082：采用 Yuanpu Planar 视觉语言重构 Viniper 工作台

- 状态：Accepted
- 日期：2026-08-14
- 产品：Viniper Harness `0.0.1 Preview`

## 背景

用户要求从 `yuanpu.cc` 的前端模板中选择一个符合 Viniper Harness 的方向，在不改变冷青主色、Agent 后端能力与三栏信息架构的前提下，重构桌面端全部主要与衍生页面，并以 Windows 真窗口截图交付。

候选对比后选择 Planar 的视觉语言。它的安静留白、低噪声边框、编辑式层级和克制悬浮面更适合长时间运行的 Agent 工作台；高饱和营销页、紫粉霓虹和重玻璃效果会削弱代码、Token、权限与运行状态的可读性。

## 决策

1. 只借鉴 Planar 的视觉语言，不复制第三方模板源码、品牌、文案或资产。
2. 保留 Viniper 的左会话、中 Agent、右侧按需改动抽屉；不把桌面端改成终端壳或仪表盘。
3. 继续使用巳月仙人模式方向的冷青色与 V 品牌；标题栏、主工作台、弹层和衍生页面使用同一套边框、圆角、阴影与字体节奏。
4. 顶栏和低风险操作以 SVG 图标为主，并提供 `aria-label`、`title` 与悬停说明；新建会话、删除、取消等关键或高风险动作保留文字。
5. Token 使用按需弹层，明确区分 Context、实时估算、Provider、Cache 和会话累计。缓存 read/write/miss 在窄空间改为纵向值行，禁止省略 Provider 未返回状态。
6. 桌面宽屏保持三栏；小于 1180px 时复用现有抽屉式侧栏，让主列占满窗口。`960×720` 是必须真窗复核的紧凑尺寸。
7. 图标外框由 `rx=20` 调整为 `rx=24`，保持 V、电路节点和主色不变；原生 PNG/ICO 继续复用已验证的圆角资产。

## 边界

- Renderer 继续只消费 application port，不新增 Provider、文件、SQLite 或明文密钥直连。
- 不改变权限三档、Skill/插件启用、外置 CLI、会话排序、改动审查与恢复合同。
- macOS 只同步共享 renderer 草案；交通灯安全区、Dock/AppIcon、Retina、VoiceOver、签名和公证必须真机验证。

## 验证门

- UI 合同测试与全量回归通过。
- Windows 原生 Electron 窗口至少在 `1440×900` 与 `960×720` 实际观察。
- Token 弹层长状态无截断；Provider、Skills/插件、右侧改动抽屉与设置页保持可用。
- 新包覆盖安装后由桌面快捷方式启动，并从安装目录验证进程来源。
