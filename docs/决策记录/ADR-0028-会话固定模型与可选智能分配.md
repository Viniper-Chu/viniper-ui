# ADR-0028：会话固定模型并提供可选智能分配

- 状态：Accepted
- 日期：2026-08-13
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

所有任务都手动选模型最可控，但对子任务和多 Agent 协作过于繁琐；完全自动路由又会让能力、隐私、延迟和缓存表现不可预测。用户选择方案 C：每个会话默认固定模型，用户可选启用对子任务的智能分配，选择过程必须透明且运行中不得偷偷换模型。ADR-0059 后续明确取消模型价格比较。

## 决策

### 会话默认模型

- 每个会话保存一个明确的 Provider profile、model id 和推理强度作为默认值。
- 用户直接在当前会话提交的主任务默认使用该模型，除非用户在开始前显式选择另一个模型。
- 每个 run 开始时固定 Provider、profile、model、推理强度、endpoint、能力和缓存身份；同一 run 的工具续轮、Provider 重试和自动审查都遵守该快照。
- 运行中不得因速度、错误、余额或路由判断静默切换 Provider 或模型。当前模型失败时先按 ADR-0023 重试同一请求，仍失败则停止并提供“使用其他模型重新运行”的显式新任务入口。
- ADR-0053 的成功目录刷新若发现模型已消失，只从未来选择中立即移除；活动 run 保持冻结快照，引用该模型的会话在下一次运行前要求用户明确改选。

### 可选智能分配

- “智能分配”默认关闭，可按会话、委派或自动任务显式开启。
- 启用后的默认偏好为“均衡”，用户可按会话或单次任务切换“质量优先 / 均衡 / 轻量优先”；具体语义见 ADR-0035/0059。
- 它只为尚未开始的委派、子任务或新隔离 run 选择模型；不会夺走主任务已经固定的模型，也不会改写活动 run。
- 候选模型只能来自用户已配置、已启用并允许参与智能分配的 profile，不能把任务发送给未配置的厂商。
- 路由器在本地根据任务需要的上下文、工具调用、视觉/文件能力、推理档位、用户选择的“质量 / 均衡 / 轻量”偏好、用户排序、缓存、延迟和当前 Provider 可用状态做确定性筛选；不读取价格，也不把完整任务先广播给多个模型进行海选。
- 多个候选都满足时优先保持会话模型或同一缓存身份，减少前缀重新预热；只有能力、用户偏好或容量事实证明更合适时才选择其他模型。

### 可解释与可覆盖

- 开始前或任务卡创建时显示将使用的模型和简短原因，例如“需要图像输入”“优先保持当前会话缓存”“选择用户允许的轻量模型”。
- 选择原因只展示能力、用户偏好、缓存、延迟、上下文和可用性，不展示价格或金额。
- 用户可以在开始前改选或固定模型；一旦 run 开始，改选只影响下一次运行。
- 路由决定、候选排除原因和最终模型进入审计事件，但不记录 API Key 或隐藏推理。

## 缓存与隐私

- 不同 Provider/profile/model 的缓存统计分别记账，不能把跨模型请求算成缓存延续。
- 为提高命中，固定系统指令、工具 schema、项目指令、启用 Skills 和适用记忆仍按稳定顺序组成前缀；路由变化只影响新 run。
- 智能分配不扩大工具权限、项目权限、记忆范围或第三方数据授权；模型获得的上下文仍由当前 run 合同决定。

## 产品表现

- 模型选择器显示“固定：模型名”或“智能分配：均衡”等清楚状态。
- 委派卡在开始前显示实际模型、原因、能力和缓存影响；运行中不出现模型突然跳变。
- 失败后提供重新运行入口，不把换模型伪装成同一次重试。

## 收益

- 普通会话保持稳定、可预期和有利于缓存。
- 多 Agent 子任务不需要用户逐项挑选模型。
- 用户仍能知道数据发给哪个厂商、为什么选择以及缓存是否延续。

## 代价

- 本地路由规则需要维护各模型能力、上下文和状态元数据。
- 为保持透明和缓存，路由不会总选择理论上最快的模型。
- 模型失败后不自动切换，用户需要显式发起新的运行。

## 与既有决策的关系

- 自动审查仍按 ADR-0012 和 ADR-0015 使用本次执行 run 已固定的模型与推理强度。
- Provider 临时错误仍按 ADR-0023 最多尝试 5 次，不把模型切换算成重试。
- ADR-0035 确定三档偏好的默认值与比较原则；ADR-0059 将“节省”修订为“轻量优先”并移除全部价格输入。具体 Provider 能力和状态属于持续维护的实现证据，未知数据不得凭印象填充。
- ADR-0053 细化模型目录生命周期：消失模型不再进入新任务或智能候选，但历史 run 的 model id 永久保留。
- ADR-0058 允许云端与本地模型进入同一候选合同，但云端失败不静默切换本地，本地候选也必须由用户明确允许。
- ADR-0064 的实验性提示词工具模拟只有在用户为具体模型开启后才能满足工具候选条件；ADR-0065 的本地资源容量只能让候选排队，不能在运行中改换模型。
