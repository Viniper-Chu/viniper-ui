# ADR-0062：本地模型支持内置来源与本地或自定义导入

- 状态：Accepted
- 日期：2026-08-13
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

只允许导入本地文件最可控，但普通用户需要自行寻找、下载和识别模型；只允许内置目录最简单，却会限制高级用户和已有模型资产。用户选择方案 C：本地模型中心同时提供内置已知来源、本地文件导入和自定义来源，并在取得模型前清楚显示来源与许可信息。

## 决策

### 三种明确来源

- 内置目录列出 Viniper 已适配的已知下载来源、模型格式和运行器兼容信息；“内置”表示维护接入元数据，不代表对模型质量、许可或用途作担保。
- 用户可以导入本机已有模型文件。预览版默认复制到 Viniper 受管模型库并保留原文件不变；导入前显示新增磁盘占用，后续删除只作用于受管副本。
- 高级用户可以填写自定义下载地址或模型仓库地址。需要鉴权时，凭据进入 `PlatformCredentialVault`，不会写进模型元数据、日志或导出清单。
- 三种来源都必须由用户明确选择并确认下载或导入；打开应用、创建会话和云端失败都不会触发自动获取。

### 来源与许可可见

- 取得模型前显示来源类型、发布者或来源地址、模型名称、格式、量化版本、预计下载/导入体积、已知运行器兼容性和许可说明。
- 无法确认的发布者、许可或硬件要求如实标记“未知”，不伪造成已验证；用户仍可选择继续导入自有文件或自定义来源。
- 安装记录保存来源、版本/修订、格式、量化和导入时间，以便更新提示、版本切换和问题定位；不得把这些字段解释成模型内容审查结论。
- Agent、模型和插件没有新增、替换或修改来源记录与模型权重的自主工具；模型生命周期仍由用户操作。

### 统一模型库与能力合同

- 不论来源，本地模型都进入 ADR-0058 的统一 `LocalModelService` 和 ProviderAdapter，不建立来源专属 Agent 循环。
- 下载或导入完成只表示文件可用；上下文、流式、工具调用、结构化输出和硬件兼容仍需单独探测或验证。
- 内置目录和自定义来源的网络访问遵守普通下载、代理、取消和断点续传边界；本地文件导入不触发外部网络请求。

## 产品表现

- 本地模型页提供“从已知来源获取 / 导入本地文件 / 添加自定义来源”三个平级入口。
- 模型卡片持续显示来源、许可、版本、体积、运行状态和能力等级，并允许打开来源详情。
- 未知信息使用普通语言说明，不用笼统的“安全”“官方”或“完全兼容”标签代替证据。

## 收益

- 新手可以从已适配目录开始，高级用户不会被锁在单一模型来源。
- 模型来源、许可和运行能力分开表达，减少误导。
- 已有本地模型可以复用，同时保持受管模型库的稳定路径。

## 代价

- 需要维护来源元数据、导入流程和自定义下载兼容性。
- 复制导入会增加磁盘占用，但避免原文件移动或失效影响已配置模型。
- 自定义来源的许可和兼容信息可能不完整，需要在界面持续标明未知项。

## 与既有决策的关系

- 细化 ADR-0058 的本地模型发现、下载和生命周期入口，不改变云端 API 默认主路径。
- 凭据继续由 ADR-0010/0057 的平台 Vault 与独立加密迁移边界管理；模型权重仍按 ADR-0052 只能由用户明确删除。
- 本 ADR 是后续目标设计；来源目录、本地复制导入、自定义下载、许可展示和真机运行均为 `UNPROVEN`。
