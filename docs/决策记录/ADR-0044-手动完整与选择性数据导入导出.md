# ADR-0044：提供手动完整与选择性数据导入导出

- 状态：Accepted
- 日期：2026-08-13
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

只导出单个会话最容易实现，但不利于迁移整套 Harness 数据；直接复制整个数据目录又会混入凭据、运行锁和平台相关状态，并可能覆盖当前正式数据。用户选择方案 C：同时提供手动完整数据归档，以及按会话或项目选择的导出与导入；秘密默认不进入归档。

## 决策

### 两种手动导出

- **完整归档**覆盖当前数据根中的非秘密业务数据，包括会话、run、任务、Token/缓存账本、项目/个人记忆、Provider profile 的非秘密配置、扩展清单与信任元数据、调度定义、结构化审计事件，以及用户勾选的受管产物。
- **选择性归档**允许按一个或多个会话、规范项目及其关联记忆、任务和受管产物导出；选择“项目”只表示 Harness 与该项目关联的数据，不会静默复制用户的整个 Git 仓库或外部项目目录。
- 每份归档都包含版本化 manifest，列出来源版本、导出时间、数据范围、关联数量、是否包含大型受管产物，以及明确排除项。
- 大型日志、构建物和下载等受管产物默认先展示体积，由用户决定是否随归档带走；缺少可选产物不影响结构化历史的导入，但必须标记为“产物未包含”。

### 秘密默认排除

- API Key、访问令牌、验证码、私钥、代理凭据、客户端证书私钥和 `PlatformCredentialVault` 中的任何明文秘密不进入普通完整或选择性归档。
- 归档可以保留“某个凭据引用曾存在、导入后需要重新配置”的非秘密占位信息，但不能包含可用于鉴权的值。
- 普通归档永久保持非秘密。ADR-0057 另行提供独立、用户主动操作的密码加密密钥包；它不能被普通归档默认勾选或混装。

### 导入先暂存、验证和预览

- 导入文件先进入受管暂存区，Runtime 校验 manifest、格式版本、引用完整性和可支持的迁移路径，在写入正式真源前显示预览。
- 预览至少显示将新增或合并的会话、项目、记忆、任务、扩展元数据和产物数量，以及缺少秘密、版本不兼容、引用缺失和标识冲突。
- 默认行为是合并：已有正式数据不被静默覆盖，发生标识冲突时为导入对象分配新标识并保留来源关联。只有用户明确选择一个空白或隔离数据根时，才允许把完整归档作为该数据根的初始内容。
- 导入失败不得留下“部分成功但界面显示完成”的状态；结构化写入和受管文件登记按同一导入事务收口，失败时保留原数据并给出可处理原因。
- 导入不会自动启用扩展、恢复已过期的电脑完全访问、信任新项目、启动调度任务或发起 Provider 请求；这些运行状态仍按各自 ADR 重新判断。

### 手动归档不是自动备份

- 只有用户主动发起导出时才创建归档；Runtime 不按日、周、启动、退出、更新或数据量自动生成。
- ADR-0039 的“不提供日常自动备份”保持不变。导出文件由用户选择保存位置和生命周期，Harness 不把它显示为已经验证可恢复的自动备份。
- 导出完成只证明文件已写出；可选的“验证归档”需要重新读取 manifest 与内容引用，结果单独显示，不能仅凭文件存在宣称可恢复。

## 产品表现

- 设置中的“数据与迁移”提供“导出全部非秘密数据”“选择会话或项目导出”“从归档导入”三个普通语言入口。
- 导出前用清单显示“会带走什么 / 不会带走什么”；导入前用差异预览显示新增、合并、缺失和冲突，不要求用户理解 SQLite。
- CLI 使用同一 Runtime 服务，交互模式可选择范围；非交互模式必须显式给出范围与目标，不能默认导入覆盖当前数据根。

## 收益

- 用户既能迁移整套 Harness，又能只分享或保存某个项目/会话。
- 秘密与便携数据分离，跨设备迁移不会顺便泄露 Provider 或代理凭据。
- 暂存、预览和合并降低把现有正式数据覆盖掉的风险。

## 代价

- 版本迁移、关联重映射和大型产物选择会增加实现与测试量。
- 导入后需要重新配置秘密，并重新判断权限、扩展启用和调度状态。
- 手动归档不能替代持续备份；用户不主动导出时仍没有产品恢复点。

## 与既有决策的关系

- 补充 ADR-0032 的 SQLite 与受管文件迁移边界，并保持结构化真源和文件引用的一致性。
- 不修改 ADR-0039：本 ADR 只提供用户主动的数据可携带能力，不创建周期性、滚动或云端自动备份。
- 遵守 ADR-0030/0037/0038 的记忆与会话生命周期，也不因导入恢复秘密、权限或 Agent 自修改能力。
- ADR-0050 已确定本机数据不自动同步；本 ADR 是普通非秘密数据的唯一产品内跨设备路径，ADR-0057 另管 portable 秘密，导入后各设备数据独立发展。
- ADR-0057 只为 portable Vault 秘密增加独立密钥包，不改变本 ADR 的普通归档内容和导入事务。
- 本 ADR 是后续目标设计；当前完整归档、选择性导出、导入预览和跨版本恢复均为 `UNPROVEN`。
