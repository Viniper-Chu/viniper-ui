# ADR-0058：云端模型为主并提供可选内置本地模型运行能力

- 状态：Accepted
- 日期：2026-08-13
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

只接云端 API 最容易维护，但无法满足离线、隐私或本地硬件利用场景；只支持用户自行启动的兼容端点门槛较高；在产品内提供本地模型下载与运行能力则更易用，但会明显增加体积、硬件适配和生命周期管理。用户选择方案 C，并补充“以云端为主”：Viniper 保持云端 Provider 为默认主路径，同时提供用户主动启用的本地模型运行能力。

## 决策

### 云端始终是默认主入口

- 首次设置、快速开始、新建会话和 Provider 推荐顺序以用户配置的云端 API 为主；本地模型放在独立的“本地模型”入口，不要求新手先安装模型。
- 应用安装包默认不附带模型权重，也不在安装、启动或云端失败时自动下载本地模型。
- 云端请求失败、余额不足、限流或模型下线时，不静默切换到本地模型；用户必须明确选择本地 profile，或主动允许其进入 ADR-0028 的智能候选。

### 同时支持外部端点与内置运行器

- 高级用户可以连接自己已经启动的 OpenAI-compatible 本地端点；其 endpoint、模型和能力继续由普通 Provider profile 管理。
- 内置本地模型中心负责兼容模型的发现、用户确认下载、运行器安装、启动/停止、磁盘位置和删除；模型来源、许可说明、下载体积和已知硬件要求在下载前可见。
- “内置”表示 Viniper 管理运行器和本地模型生命周期，不代表把模型塞进主安装包，也不代表 Viniper 自己训练或修改模型。
- 内置服务默认只监听本机回环地址，并随当前 Runtime 所有者启动或停止；不开放局域网端口、不安装永久系统服务，也不成为跨设备 Runtime。

### 与统一 Agent Runtime 对接

- 本地模型通过与云端相同的 ProviderAdapter、结构化历史、ToolRegistry、权限、Token 账本、取消和审查合同接入，不建立第二套 Agent 核心循环。
- 每个本地模型实际支持的上下文、流式输出、推理、工具调用和结构化结果必须由模型/运行器能力合同确认；不支持的能力在界面关闭，不能只凭模型名猜测。
- 本地模型仍固定到 run snapshot；运行中不得替换权重、运行器或量化版本。Agent、插件和模型本身都没有修改 Viniper Runtime 或模型权重的工具。

### 存储与平台边界

- 用户明确安装的模型权重属于用户管理的本地产物，只能手动删除，不进入 ADR-0052 的周期清理；未完成下载块和可重建转换缓存可以按可再生成产物处理。
- Windows 原生运行、显卡/CPU 识别、断点下载、磁盘检查和卸载是首个实现目标；macOS arm64/x64、Apple Silicon 加速和真机资源表现同步做草案但保持 `UNPROVEN`。
- 本地模型运行不需要 API Key；外部兼容端点若配置鉴权，秘密仍进入 `PlatformCredentialVault`。

## 产品表现

- 模型选择器默认先展示已配置云端模型，并提供清楚的“本地模型”分组，不用“免费”或价格标签诱导选择。
- 本地模型页显示未安装、下载中、可运行、运行中、停止、资源不足和不兼容等状态，并提供普通语言说明。
- 用户选择本地模型时显示“只在这台设备可用”；通过数据归档迁移会话不会自动复制模型文件。

## 收益

- 普通用户仍获得简单的云端 API 路径，高级用户可以离线或在本机运行。
- 外部本地端点和产品管理运行器都能复用同一 Agent 能力。
- 不把大型模型权重强加给所有安装用户。

## 代价

- 本地推理会增加下载、磁盘、硬件检测、运行器更新和故障诊断工作。
- 不同模型的工具能力与输出质量差异较大，不能宣称与主流云端模型等价。
- Windows 与 macOS 的加速后端、驱动和资源限制需要分别真机验证。

## 与既有决策的关系

- 扩展 ADR-0028/0035/0053 的 Provider、模型目录和 run 固定模型合同；不允许云端与本地之间静默回退。
- 本地服务遵守 ADR-0031/0050 的单设备、单 Runtime 所有者和无远程 Runtime 边界。
- ADR-0062 细化内置/本地文件/自定义来源，ADR-0063 规定更新只提醒并确认切换，ADR-0064 规定原生/实验/无工具能力，ADR-0065 规定资源感知且默认单路本地推理。
- 本 ADR 是后续目标设计；内置运行器、模型下载、工具能力、Windows 硬件兼容和 macOS 真机均为 `UNPROVEN`。
