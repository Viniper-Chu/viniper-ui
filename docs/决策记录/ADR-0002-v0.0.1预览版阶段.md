# ADR-0002：v0.0.1 预览版阶段

状态：Accepted
日期：2026-08-12
决策人：用户 / Agent Desktop 管理层

## 背景

当前只有第一条可运行纵切与 Demo Provider，尚未推送最早的公测更新。用户明确要求：无论当前内部迭代多少次，产品身份都只能是 0.0.1 或预览版中的更新。

## 决策

1. 产品版本固定为 `0.0.1`。
2. 发布阶段固定为 `Preview / 预览版`。
3. 应用内统一显示 `v0.0.1 · Preview（预览版）`；`package.json` 使用 `0.0.1`。
4. 当前及后续同阶段改动只能称为“预览版内部更新”，不得称为 Beta、公测、RC、正式版或首次公测更新。
5. 未经用户新的明确决策，不提升版本阶段，也不创建公开 Release 或远端标签。

## Git 追溯

本决策发生在第一个“需求与目录基线”提交之后，不改写既有提交；新增独立的“固定 v0.0.1 Preview 阶段”提交保存决策，再继续纯 Agent 实现和验证提交。

## 影响

- 包元数据、窗口标题、设置/关于页、执行报告和测试断言需要统一。
- Demo Provider 与未完成的 Viniper 功能必须继续清楚标注，不能因能启动就暗示达到公测质量。
