# ADR-0008：完全访问分级持续时间

- 状态：Accepted（Runtime 所有权交接语义由 ADR-0031 补充）
- 日期：2026-08-12
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

ADR-0007 已确定同时提供“项目完全访问”和“电脑完全访问”。下一步需要决定权限在任务结束或应用重启后是否保留。用户选择分级记忆：日常项目可以被长期信任，整机权限则不跨应用或 CLI 重启。

## 决策

### 所有完全访问都支持“仅本次任务”

- 项目完全访问和电脑完全访问都可以只授予当前 run。
- 当前 run 完成、取消或失败后，权限自动恢复为普通按需确认。
- 该选择适合一次性修改、临时诊断和用户尚不准备长期信任的项目。

### 项目完全访问支持“信任此项目”

- 用户可将当前显式选择的工作目录标记为受信任项目。
- 该项目的完全访问授权跨 Viniper Harness 重启保留，直到用户主动撤销。
- 新会话只有在显式绑定同一受信任项目后才能使用这项权限；这不会共享普通会话历史、任务或临时上下文。项目记忆是否共享只按 ADR-0030 的独立用户控制规则判断。
- 桌面端和 CLI 都显示“项目完全访问 · 已信任”，并提供直接撤销入口。

### 电脑完全访问支持“直到完全退出”

- 用户可让电脑完全访问持续到当前 Runtime 所有者进程退出。桌面/CLI 所有权按 ADR-0031 交接时，整机授权令牌不随 IPC 转移，原令牌立即失效，新所有者需要重新授权。
- 桌面窗口最小化或进入后台不视为完全退出；界面显示“电脑完全访问 · 退出后恢复”。
- 电脑完全访问按会话保持，不能因为一个会话获权而自动赋予其他并行会话。
- 该授权只保存在当前进程内存中，不写成跨重启授权；下次启动恢复普通按需确认。

## 产品表现

- 权限按钮同时显示“范围 + 持续时间”，不只显示含糊的“完全访问”。
- 常用文案固定为：
  - `项目完全访问 · 本次任务`
  - `项目完全访问 · 已信任`
  - `电脑完全访问 · 本次任务`
  - `电脑完全访问 · 退出后恢复`
- 用户可以在任务进行中降低权限或停止任务；提高权限仍需要用户明确选择。
- 权限到期时只给一次简短状态提示，不使用反复打断用户的确认框。

## 收益

- 经常使用的编程项目不需要每次启动重新授权。
- 整机自动化可以连续完成一组操作，又不会永久留在整机完全访问状态。
- 并行会话继续保持权限隔离；一个会话的整机权限不会外溢到其他会话。
- 桌面端与 CLI 的生命周期都容易理解和实现。

## 代价

- 产品需要分别维护 run、会话、进程和受信任项目四种关联信息。
- 用户移动到另一个项目时，需要重新选择是否信任。
- 桌面端若未来加入后台常驻，必须清楚区分“关窗口”和“完全退出”。
