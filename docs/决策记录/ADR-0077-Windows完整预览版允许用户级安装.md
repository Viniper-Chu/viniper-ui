# ADR-0077：Windows 完整预览版允许用户级安装

- 状态：Accepted
- 日期：2026-08-13
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

ADR-0071 在早期频繁迭代阶段只允许交付 Windows x64 便携包。Phase 7 的编程 P1–P4、原生 Tray、便携包直接启动和本地 fake E2E 已完成离线验收。用户现要求补完其余已决定功能，并在全部本地验收后安装到本机，桌面只保留一个快捷方式，API Key 由用户稍后自行配置。

## 决策

- 当前 Windows 目标仍是 `0.0.1 Preview`，但允许生成和执行可复现的 x64 用户级安装。
- 便携包继续作为诊断、回退和全新解压复验产物；用户级安装目录是本轮日常启动的正式本机产物。桌面快捷方式与 CLI 均消费正式单一 Runtime 和同一数据真源，不能从便携目录再启动第二 Runtime。
- 默认程序目录为 `%LOCALAPPDATA%\Programs\Viniper Harness Preview\`；不要求管理员权限，不安装 Windows 服务、计划任务、开机项或文件关联。
- 桌面只创建 `Viniper Harness.lnk`。快捷方式的目标、工作目录和图标必须指向正式安装目录，不指向源码、stage 或便携验证目录。
- 程序目录与用户数据根分离。安装、重装或卸载程序文件不得默认删除会话、设置、密钥引用、记忆、工具输出或其他用户数据。
- 安装必须经过最终源码构建、全量回归、全新安装、从快捷方式启动、首次设置、重启持久化、Tray/退出和版本来源验证。
- 用户未提供 Provider Key 前，正式安装不预填、不读取旧测试 Key、不发起真实 Provider 请求；设置页必须允许用户安全写入和删除凭据且永不回显明文。
- 本机安装授权不等于公开发布、上传、代码签名、SmartScreen 信誉、商店上架或远程更新渠道授权。

## 收益

- 用户可从桌面直接体验完整 Preview，无需理解源码、npm 或便携目录。
- 用户数据继续独立保存，后续替换程序文件不会自动抹掉体验数据。

## 代价

- 未签名 Preview 不能宣称通过代码签名或 SmartScreen 信誉验收。
- 在官方公网更新源尚未发布前，更新中心只能通过本地冻结源证明状态机，不能冒充真实在线更新。

## 与既有决策的关系

- 本 ADR 仅在完成任务合同 v0.11 的最终验收时覆盖 ADR-0071 的“禁止安装器/快捷方式”限制；便携包仍保留为诊断和回退交付物。
- ADR-0072 的 macOS `draft-only / UNPROVEN` 边界不变。
