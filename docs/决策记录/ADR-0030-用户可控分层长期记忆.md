# ADR-0030：采用用户可控的分层长期记忆

- 状态：Accepted
- 日期：2026-08-13
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

仅保留会话历史最清楚，但换会话后无法复用项目约定；所有项目自动共享记忆又容易串项目、形成错误画像或泄露上下文。用户选择方案 C：会话历史自动保存，项目记忆在项目内复用，跨项目个人记忆必须由用户明确保存，并且全部可查看、编辑和删除。

## 决策

### 三层记忆

1. **会话记忆**：自动持久化当前会话的普通消息、结构化 Provider history、工具/事件、Token 账本和显式协调信封，只服务该会话的恢复与后续轮次；按 ADR-0038 永久留在主列表，直至用户手动删除。
2. **项目记忆**：保存项目术语、用户确认的约定、常用命令、验收习惯和稳定事实，可供显式绑定同一规范项目的多个会话使用。
3. **个人记忆**：保存用户希望跨项目复用的表达偏好、工作习惯和通用约定；只有用户明确选择“保存为个人记忆”后才创建。

### 保存规则

- 会话层按现有会话持久化自动工作，不弹出逐条确认。
- 项目层和个人层不会从普通对话中静默推断并永久保存。用户可以直接说“在这个项目记住”或“以后都记住”，也可以接受 Agent 在任务结束时提出的可见记忆建议。
- 每条项目/个人记忆记录内容、作用域、来源会话/run、创建时间、最后修改时间和创建方式（用户直接保存或接受建议）。
- Agent 可以提出新增、修改或删除建议，但未经用户动作不能改写项目/个人记忆；这不是模型学习或修改权重。
- 凭据、验证码、私钥和 SecretVault 内容不能保存为普通记忆；记忆只可保存不含明文秘密的连接名称或引用说明。

### 读取与优先级

- 当前用户指令高于记忆；`AGENTS.md` 等项目指令高于项目/个人记忆；记忆不能授予权限、启用工具、信任插件或改变系统边界。
- 项目 run 默认只装载少量固定且仍有效的项目记忆摘要；其余内容通过只读记忆检索按需取得，避免把全部记忆塞进每次请求。
- v0.0.1 先采用本地结构化条目、标签和全文检索，不以向量数据库作为启用记忆的前提。以后增加语义检索也不能改变作用域和用户控制规则。
- 进入 Provider 上下文的记忆必须按稳定顺序放入缓存前缀，并在 run snapshot 中固定；运行中修改只影响后续 run。
- 超长会话按 ADR-0040 静默压缩后续模型上下文，但原始会话消息与事件仍完整保留；摘要不能冒充删除或改写会话历史。
- 记忆与当前事实冲突时显示来源和时间，并优先要求确认或使用当前项目事实，不把旧记忆冒充权威指令；项目/个人记忆的“可能过时”状态、90 天默认检查周期和停止自动注入规则见 ADR-0037。

### 查看、编辑与删除

- 记忆中心按“本会话 / 当前项目 / 个人”分组，支持搜索、查看来源、编辑、停用和删除。
- 删除或停用后不再进入新的 run；历史事件仍可保留“曾使用某条记忆”的审计引用，但不保留已删除的敏感正文副本。
- 已经发送给第三方 Provider 的旧请求无法从对方既有日志中追回，删除界面必须如实说明这一边界。
- 项目解除绑定不会自动删除项目记忆；用户可选择保留、导出或删除，不能静默清空。

## 产品表现

- ContextPanel 显示本次 run 使用了哪些项目/个人记忆，可展开来源，但默认不占据主执行时间线。
- Agent 建议记忆时使用一张可编辑卡片，提供“仅本项目 / 以后都使用 / 不保存”。
- 保存、修改和删除都有简短回执；不使用“模型已经学习”这种误导文案。

## 收益

- 同一项目的多个会话能复用稳定约定，同时避免自动串到无关项目。
- 用户能控制哪些偏好跨项目长期存在。
- 记忆来源、作用域和删除入口清楚，模型不能借记忆修改自身。

## 代价

- 项目/个人记忆需要用户确认，初期不如全自动画像省事。
- 记忆冲突、过期和检索需要单独的状态与界面。
- 删除只能阻止未来使用，不能撤回已经发送给 Provider 的历史请求。

## 与既有决策的关系

- 扩展 ADR-0003 的会话持久化，但不改变跨会话协调信封和普通历史隔离。
- `AGENTS.md` 继续是项目指令，不是记忆；权限、插件信任和系统边界不受记忆提升。
- ADR-0037 细化长期记忆的过时复核，并明确时间规则永不自动删除正文。
- ADR-0038 与 ADR-0040 分别决定会话主列表的永久保留和模型上下文的静默压缩；两者不改变项目/个人记忆的显式保存规则。
- 本 ADR 是目标设计升级；Phase 5 已验收的“当前没有跨项目长期语义记忆”仍是当时真实事实，不被改写成已实现。

## 后续待定

1. 导入导出范围与普通归档排除秘密已由 ADR-0044 决定；容量治理已由 ADR-0045 决定为可调软提醒且永不自动删除。初始 Preview 的具体提醒阈值必须由实现阶段真实规模与检索性能证据确定，v0.0.1 仍不以复杂 RAG 或向量数据库作为前置条件。
