# ADR-0007：双级完全访问范围

- 状态：Accepted
- 日期：2026-08-12
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

ADR-0006 已确定产品必须提供完全访问权限，但尚未决定它只覆盖当前项目还是整台电脑。只提供项目范围会限制跨目录和系统操作；只提供整机范围又会让普通编程任务承担不必要的影响面。用户选择同时提供两个级别。

## 决策

权限选择器除普通按需确认外，提供以下两个明确分开的高级级别：

### 1. 项目完全访问

- 作用范围是当前会话显式选择的项目目录。
- Agent 可在该范围内进行文件读取、创建、修改、移动和删除，并可使用代码搜索与编辑、项目终端、Git、依赖安装、构建、测试、打包和诊断工具，不再为每个正常项目操作重复询问。
- 工具明确需要作用到项目外时，不继承项目完全访问，必须回到普通权限处理。
- 界面始终显示当前授权的项目名称和路径，避免用户误以为它覆盖整台电脑。

### 2. 电脑完全访问

- 作用范围扩展到当前电脑上、当前操作系统账户本来可以访问的本地文件、命令和应用。
- Agent 可执行跨目录文件操作、系统级终端任务和本地应用操作，不再为每个本地变化重复弹出 Harness 批准。
- 它不会静默提升操作系统权限：Windows 管理员操作仍遵循 UAC，macOS 仍遵循系统隐私与授权机制。
- 运行界面必须持续显示“电脑完全访问”，并提供立即降级和停止入口。

## 两级都不包含

- 模型修改自身、修改模型权重，或自行扩大权限。
- 修改或绕过 Viniper Harness 的权限引擎、审计记录、秘密保护、预算和停止规则。
- 读取 Provider 密钥或其他秘密的明文。

## 外部操作

- 用户已经决定：任一级完全访问有效时，当前会话内已配置并启用的发布、发送、上传、付款、远程权限修改和远程删除工具不再触发 Harness 逐项确认。
- 项目级与电脑级继续决定本地文件、命令和应用的范围；外部工具以当前会话实际启用的连接为范围。
- 具体合同见 `ADR-0009-完全访问包含外部操作.md`。

## 产品表现

- 自主程度、权限级别和自动审查保持为三个独立选择。
- 桌面端和 CLI 使用相同的权限名称、范围判断和审计事件。
- 权限摘要用人话说明“能做什么、作用在哪里”，不要求新手理解沙箱术语。
- 切换到更高权限必须来自用户的明确选择；任务复杂度升级、多 Agent 分工或自动审查均不能替用户升级权限。

## 收益

- 日常编程可使用项目完全访问，减少反复确认，同时把影响控制在当前工作目录。
- 跨项目、系统维护和桌面自动化仍可通过电脑完全访问完成，不牺牲 Agent 的上限。
- 新手和高级用户共用一个产品，不需要拆出阉割版与专业版运行时。

## 代价

- Runtime 需要维护清楚的授权范围并让所有工具共用同一判断。
- 电脑完全访问的误操作影响更大，因此界面需要持续可见，不能藏在一次性提示后。
- 项目终端可能调用项目外资源；工具一旦明确超出项目范围，就需要回到普通权限流程。
