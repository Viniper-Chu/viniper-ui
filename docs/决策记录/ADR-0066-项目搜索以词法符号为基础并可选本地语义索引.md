# ADR-0066：项目搜索以词法和符号为基础，并可选本地语义索引

- 状态：Accepted
- 日期：2026-08-13
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

只做关键词和符号搜索简单、可解释，但难以找到措辞不同的相关内容；只做向量搜索会增加模型、资源和调试依赖，也不适合精确文件名与符号查询。用户选择方案 C：关键词、路径和代码符号继续作为基础能力，每个项目可以另行开启完全本地的语义索引，查询时混合并标明结果来源。

## 决策

### 基础搜索始终可用

- ADR-0056 的路径、文本、关键词和符号索引仍是默认路径；语义索引关闭、未完成、过期或失败时，Agent 继续使用基础索引与项目内实时搜索。
- 精确文件名、路径、符号和文字查询优先保留可解释的精确结果，语义相关性不能把确定命中完全挤出结果集。
- 语义功能不是完成编程 P1–P4 的前置条件，预览版可以先交付基础搜索再单独验收语义层。

### 语义索引按项目明确开启

- 用户在具体项目中选择“启用本地语义搜索”后，界面先显示需要的本地嵌入模型、预计磁盘和首次建立时间；不会因项目完全访问或电脑完全访问自动开启。
- 嵌入计算和语义索引保存在本机受管数据根，不为建立索引把项目正文发送给云端 Provider；需要下载嵌入模型时继续遵守 ADR-0062 的明确来源与确认下载。
- 语义索引遵守与基础索引相同的项目根、忽略规则、自定义排除项、暂停、重建和删除边界。
- 关闭或删除语义索引不删除基础索引和项目文件；两类索引都是可再生成产物。

### 混合检索与状态诚实

- 查询层合并词法、符号和语义候选，并保留 `lexical / symbol / semantic / live` 来源；融合规则必须可测试，不能向模型伪造统一置信度。
- 文件变化后两层分别维护新鲜度。语义层尚未更新时可以降级到基础索引和实时搜索，并显示“语义索引正在更新”。
- Agent 只取得与本次任务相关的有界结果；开启语义索引不等于把整个项目内容塞进模型上下文。

## 产品表现

- 项目设置提供默认关闭的“本地语义搜索”开关、资源说明、建立进度、暂停、重建和删除入口。
- 搜索结果默认统一排序，高级详情可以查看“精确文字、代码符号、语义相关、实时补查”等来源。
- 语义服务不可用时显示降级状态，但不阻止读取、编辑和 Agent 运行。

## 收益

- 同时覆盖精确编程查询和自然语言相关内容发现。
- 语义功能保持本地、按项目和可选，不扩大云端内容边界。
- 语义层失败不会让基础编程能力失效。

## 代价

- 需要额外模型下载、首次计算、磁盘和结果融合逻辑。
- 大项目的语义索引可能耗时明显。
- 混合排序和过期状态需要独立测试，不能只看单一搜索分数。

## 与既有决策的关系

- 扩展 ADR-0056，但保留其“基础索引 + 项目内实时回退”和零全盘扫描合同。
- 语义模型来源遵守 ADR-0058/0062，索引保留与删除遵守 ADR-0032/0052。
- 本 ADR 是后续目标设计；本地嵌入、混合排序、增量更新、降级和 Windows/macOS 性能均为 `UNPROVEN`。
