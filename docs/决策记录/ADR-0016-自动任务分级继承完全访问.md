# ADR-0016：自动任务分级继承完全访问

- 状态：Accepted（Runtime 所有权交接语义由 ADR-0031 补充）
- 日期：2026-08-12
- 决策人：用户 / Viniper Harness 管理层
- 适用版本：`v0.0.1 Preview`

## 背景

Viniper Harness 已确定支持持久化自动任务、双级完全访问和完全访问下的外部操作。需要继续决定无人值守任务是否永久继承创建时的全部权限、完全不继承，还是按权限级别继承。用户选择方案 C：受信任项目与外部工具可持久继承，电脑完全访问只在当前 Runtime 所有者进程内有效。

## 决策

### 受信任项目可以持久继承

- 自动任务可绑定一个显式选择且已受信任的项目。
- 任务定义保存项目引用和“项目完全访问”要求，跨 Viniper Harness 重启保留。
- 每次触发前重新确认该项目仍处于受信任状态；用户撤销项目信任后，相关任务立即失去该权限。
- 同一项目下的自动任务可以无人值守地编辑文件、运行项目终端、Git、构建、测试和其他项目内工具。

### 外部工具可以持久继承

- 自动任务可保存创建时显式启用的外部工具和连接引用，不保存凭据明文。
- 在有效完全访问下，任务可以无人值守地发布、发送、上传、付款、修改远程权限或远程删除，不为每次触发再次确认。
- 每次触发仍检查连接是否启用、账号授权是否有效以及 Provider 是否可用；失效时不执行对应动作。
- 外部操作完成后保存目标、动作、时间和 Provider 结果回执。

### 电脑完全访问不跨进程继承

- 自动任务可以声明“需要电脑完全访问”。
- 用户在当前桌面或 CLI Runtime 所有者进程内为该任务授权后，授权令牌只驻留该所有者内存并绑定该任务 id。
- Runtime 所有者结束或按 ADR-0031 交接时，令牌失效且不得传给新进程；任务定义只保留“需要重新授权”，不能保存一个可跨进程或重启的整机完全访问令牌。
- 重启后相关任务进入“等待重新授权”，用户恢复授权前不执行。

## 不允许静默降级

- 需要项目完全访问但项目信任被撤销时，不改用普通权限运行。
- 需要电脑完全访问但令牌已失效时，不缩小到项目范围继续。
- 外部连接失效时，不换用其他账号或连接。
- 到点未执行必须写入历史及原因；恢复后按 ADR-0018 合并补跑一次。

## 权限快照

自动任务定义保存：

- 目标现有会话或“每次新建隔离会话”；
- 项目引用与所需项目权限；
- 外部工具 id 和连接引用；
- 是否需要电脑完全访问；
- 自动审查策略和模型/profile 快照规则；
- 创建时间、修改时间和最近授权状态。

定义不得保存 Provider 密钥、账号密码或系统秘密明文。撤销项目信任、删除连接或暂停任务立即优先于历史快照。

## 产品表现

- 自动任务列表直接显示“项目完全访问 · 已信任”“电脑完全访问 · 当前已授权”“等待电脑完全访问”或“连接失效”。
- 创建和编辑页面用一句话说明任务到点能做什么，包括外部操作不再询问。
- 重新授权是任务中心的明确操作，不在后台弹出模糊对话框。
- 每次运行及自动审查结果进入该任务的历史，不与普通会话状态混淆。

## 收益

- 常见项目自动化和外部工作流可以真正无人值守运行。
- 整机权限仍遵守退出失效的既有决定，不会因为定时任务而永久化。
- 权限撤销和连接删除能立即阻止后续触发。
- 桌面端与 CLI 共用同一任务定义和授权状态合同。

## 代价

- 需要电脑完全访问的任务在 Runtime 所有者重启或交接后都要重新授权。
- 项目完全访问加外部工具仍可能无人值守执行付款、发布或远程删除。
- 调度器需要在触发前核验多类权限和连接状态。
