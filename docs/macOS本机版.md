# Viniper Mac 版

在“应用程序”中打开 **Viniper**。软件管理自己的窗口和本地后台，不需要单独打开网页或终端服务。桌面快捷方式指向 `/Applications/Viniper.app`。

## 开始任务

选择工作目录，在输入框描述目标。需要文件时点击 **+ → 添加附件**。模型名称与智能程度位于附件按钮旁的同一个菜单。已有工具能力按当前用户授权直接执行；首次使用的新能力会询问一次，选择“允许并记住”后跨会话和重启保留。上下文圆环随实际用量顺时针填充。

普通任务按 Enter 发送。Shift Enter 换行。任务运行时，Enter 将新消息排队，**引导 / ⌘Enter** 立即中断当前生成并把补充要求送入下一次模型请求。可取消的工具走正常停止流程，尚未开始的旧操作跳过；已经完成的更改保留。对话依次显示原回答、引导、新回答，重新打开会话也保持这一顺序。停止按钮取消当前运行并保留已经完成的操作。

## 规划、目标与定时任务

- **规划模式**只向模型提供只读工具。查看方案后点击“按此计划开始实施”，即可确认下一次执行任务。
- **目标模式**围绕一个明确成果自动推进。默认最多 12 轮；达到上限可主动继续。没有工具进展、遇到错误或需要补充信息时停止续轮。暂停不强杀正在执行的工具；要终止当前运行可另点停止。
- **定时任务**位于左侧任务页，支持创建、修改、暂停、恢复和删除。关闭窗口后应用仍在菜单栏运行，计划继续生效；⌘Q 完全退出后不执行，重新启动跳过离线错过的时刻。电脑睡眠时无法执行；如果应用进程一直保留，唤醒后会将已到期任务合并执行一次，再按下一时刻调度。忙会话也只保留一次待执行任务。软件没有安装退出后运行的系统守护服务。

## 阅读结果

思考、工具调用和回复按实际发生顺序穿插显示。思考与工具详情默认收起，可逐段展开；点击回答上方用时可统一展开本轮思考。执行记录使用具体的中文动作名称，并保留实际参数、回读和失败信息；文件结果卡显示完整文件名和所在目录，可直接打开。命令详情显示实际退出码、标准输出和错误输出；较长的输出可以分段继续读取，应用重启后仍可查看已保存的记录。数学公式直接排版，代码仍可复制。点击文件路径或 Markdown 文件链接打开本机文件；网页链接交给默认浏览器。会话左侧的短横线可跳到各条历史消息。

## 设置与数据

左侧每条历史会话右边的 **…** 提供重命名、置顶/取消置顶和删除，也可以右键会话打开同一菜单。置顶项显示图钉并排在列表顶部，名称和置顶状态在重启后保留。操作其他会话不会切走当前对话或清空草稿；删除需确认，项目文件保留，运行中的会话须先停止。删除当前会话时，未发送内容会保留到新会话。

设置页包含服务地址、模型、密钥、主题、字号、默认工作目录和长期协作规则。密钥由本机安全存储保护；留空会保留现有密钥。内置文档、数据、项目和网络工具的状态可以在技能与插件页查看；只有实际已注册的工具才显示可用。

本次改名保留 `~/Library/Application Support/Viniper workstation` 数据目录以及旧签名身份，以维持会话、设置和钥匙串连续性。不要手动删除该目录。Claude Code 改回独立终端使用，应用不再提供它的界面；它的旧数据仍保留。

常用快捷键：⇧⌘K 快速查找会话、常用工作和页面，⌘K 新会话、⌘B 收起/展开侧栏、⌘, 设置、⌘Enter 运行中引导。

## 2.2 界面

界面提供明亮与石墨主题，使用系统中文字体。首页可以直接选择工作目录，选择“解一道题”“检查证明”“读图解题”或“编译讲义”，再补充题干或附件即可发送。侧栏和工具栏采用统一控件，对话正文可以选择从“更小”到“更大”的五档字号。有消息时，窗口右上角的“会话目录”可以跳到一次提问或引导，也可以直接打开本会话已经生成的文件。

题干完整时可直接在对话中解题。参数能写成未知数的二次函数时，精确根数工具会按端点和顶点的函数值核对全部分段，也能验算单个方程。独立解题时，模型可一次核对多组方程或定义域，参数根数表分别列出顶点左、右两支和共同顶点，按原定义域的开闭端点精确计数；顶点是解时只计一个不同根。求解阶段按所选推理档位运行；批量核验成功后，书写阶段依据原题与精确回执直接组织推导。编译独立讲义时，题图进入学生版和教师版，解析辅助图只进入教师版。已有数学项目沿用自己的题源与编译入口。

技能与插件按名称或工具 ID 查找，插件详情能再按工具名称或 ID 筛选。可写的本地技能说明可以在详情中编辑。目标与定时任务可以同时按状态和关键词筛选，点名称进入详情，暂停且空闲的目标与 Cron 定时任务可编辑。保存或取消回到详情，再按 Esc 或点列表名称会恢复原筛选、列表位置与焦点。按 ⇧⌘K 输入“主题”“默认工作目录”等字段名会直接跳到对应设置，在独立设置侧栏也可以按字段或“字号”等关键词查找。外观页可以比较三种主题并预览公式，点“返回应用”会回到进入前的会话或详情。完成编辑后点击“保存设置”，或点击“撤销更改”恢复。

模型、智能程度和任务模式对应实际后端能力；引导、排队、停止、工具授权、历史定位与文件打开保持原有语义。菜单支持方向键选择、Esc 返回触发按钮；系统启用减少动态效果时关闭装饰动画。

## 运行中的提示

2.2.2 在左侧会话名称旁显示“进行中”或“等待确认”，输入框上方持续显示实际步骤、最近工具和用时，点击“查看进展”回到最新位置。用户上滚阅读后，新内容和任务结束不会强行拉回底部。新能力确认卡片按内容自适应，长命令单独滚动。

长数学文档可分批保存完整题目到JSON或JSONL，再通过文件路径生成；生成前核对原计划题数和独立章节。输出被模型上限截断时会明确显示不完整，不能视作完成交付。编译成功也不代表数学、题源或完整解析已经验收。

输出过程中切换或重新打开会话会继续接收内容，表格换行和代码缩进保留。会话区域支持键盘 Home、Page Up 和方向键滚动。停止后先显示“正在停止”，收到实际取消结果后显示“已停止”；正在停止时可先输入下一步，完成后再发送。

如果本地模型触发内存保护，软件会显示暂停原因并保留输入，恢复服务后再发送。软件不会自行解除模型的保护暂停。
