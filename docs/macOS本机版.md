# Viniper 2.0 Mac 版

在“应用程序”中打开 **Viniper**。软件管理自己的窗口和本地后台，不需要单独打开网页或终端服务。桌面快捷方式指向 `/Applications/Viniper.app`。

## 开始任务

选择工作目录，在输入框描述目标。需要文件时点击 **+ → 添加附件**。模型名称与智能程度位于同一个菜单；访问权限用图标区分，“完全访问”以红色提示。上下文圆环随实际用量顺时针填充。

普通任务按 Enter 发送。Shift Enter 换行。任务运行时，Enter 将新消息排队，**引导 / ⌘Enter** 立即中断当前生成并把补充要求送入下一次模型请求。可取消的工具走正常停止流程，尚未开始的旧操作跳过；已经完成的更改保留。对话依次显示原回答、引导、新回答，重新打开会话也保持这一顺序。停止按钮取消当前运行并保留已经完成的操作。

## 规划、目标与定时任务

- **规划模式**只向模型提供只读工具。查看方案后点击“按此计划开始实施”，即可确认下一次执行任务。
- **目标模式**围绕一个明确成果自动推进。默认最多 12 轮；达到上限可主动继续。没有工具进展、遇到错误或需要补充信息时停止续轮。暂停不强杀正在执行的工具；要终止当前运行可另点停止。
- **定时任务**位于左侧任务页，支持创建、修改、暂停、恢复和删除。关闭窗口后应用仍在菜单栏运行，计划继续生效；⌘Q 完全退出后不执行，重新启动跳过离线错过的时刻。电脑睡眠时无法执行；如果应用进程一直保留，唤醒后会将已到期任务合并执行一次，再按下一时刻调度。忙会话也只保留一次待执行任务。软件没有安装退出后运行的系统守护服务。

## 阅读结果

思考和工具详情默认收起，点击回答上方的用时展开。执行记录使用具体的中文动作名称，并保留实际参数、回读和失败信息；文件结果卡显示完整文件名和所在目录，可直接打开。命令详情显示实际退出码、标准输出和错误输出；较长的输出可以分段继续读取，应用重启后仍可查看已保存的记录。数学公式直接排版，代码仍可复制。点击文件路径或 Markdown 文件链接打开本机文件；网页链接交给默认浏览器。会话左侧的短横线可跳到各条历史消息。

## 设置与数据

设置页包含服务地址、模型、密钥、主题、字号、默认工作目录和长期协作规则。密钥由本机安全存储保护；留空会保留现有密钥。内置文档、数据、项目和网络工具的状态可以在技能与插件页查看；只有实际已注册的工具才显示可用。

本次改名保留 `~/Library/Application Support/Viniper workstation` 数据目录以及旧签名身份，以维持会话、设置和钥匙串连续性。不要手动删除该目录。Claude Code 改回独立终端使用，应用不再提供它的界面；它的旧数据仍保留。

常用快捷键：⌘K 新会话、⌘B 收起/展开侧栏、⌘, 设置、⌘Enter 运行中引导。
