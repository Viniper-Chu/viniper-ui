## 2. 产品、秘密与外部边界

- 产品固定为单一 Agent 工作区与 `v0.0.1 · Preview（预览版）`；不得恢复 Chat 模式或改称 Beta、公测、RC、正式版。
- 权威 cwd 为 `D:\Agent`。临时日志、截图、测试输出和一次性脚本只进入项目 `codex` 分类目录。
- Viniper 仓库、进程、数据、配置、凭据、会话和制品均不在写入或停止范围。
- 用户在管理会话粘贴过的 Key 不属于执行输入；不得读取、复述、记录、测试或用于请求。本阶段公网 Provider 调用固定为 0。
- 允许 Demo Provider、本地 fake HTTP/SSE、项目内只读 Demo 工具和 Electron `safeStorage` 边界；禁止付费、发布、上传、任意 shell、真实项目写文件工具和未知第三方代码执行。
- 不生成或报告摘要值；验证强度与真实风险相称。

## 3. 架构、数据与 Git

- 生产源码遵循 `core / features / platform / renderer` Feature Folder Contract；新增职责落入 coordination、telemetry、scheduler、skills、plugins、secrets、platform/security 及对应 renderer/test 功能域。
- `core` 不依赖 Electron、DOM 或具体 Provider；renderer 只消费 canonical snapshot；desktop/preload 暴露窄 IPC；跨域经 core 合同和窄应用服务协作。
- 本 v0.3 执行合同的已实现基线仍是同一会话串行、不同会话并行；产品现行目标已由 `DESIGN.md` 与 ADR-0025 至 ADR-0067 扩展。执行层只有在新的管理任务合同明确发布对应范围后才能改代码；无论新旧阶段，运行控制、上下文、Token、Provider、Skill/扩展快照、错误和取消信号都必须按 run 隔离。
- 本 v0.3 合同仍以现有 `sessions.json + events.ndjson` 向前迁移，并保持 coordination、usage、schedule、extension metadata、secret references 与秘密本体分开持久化。ADR-0032 已把后续目标改为 SQLite 结构化真源 + 受管文件产物，但本合同不授权建库、迁移、切换入口或删除旧数据。
- 本 v0.3 合同仍只允许 Skill 元数据发现、按需加载正文和项目内置 coordination plugin 注册本地能力，外部声明式或无效插件不执行。ADR-0036 的公共市场发现与直接安装属于后续目标，未发布新合同前不得据此下载或执行第三方扩展。
- ADR-0038 至 ADR-0067 同样不授权执行层改会话保留、创建/取消备份机制、建立账号或跨设备同步、导出或导入当前用户数据/秘密、读取真实 Vault、清理任何现有文件、索引用户真实项目、建立语义索引、下载/导入/更新/启动/切换本地模型、开启实验工具模拟、提高本地推理并发、运行后台索引节流、改变调度时区、刷新真实模型目录、迁移完整工具输出、发送系统通知、改变价格/用量字段、记录用户真实详细日志、回退任何真实扩展、自动压缩上下文、上传诊断、更新任何扩展、改代理/证书、开启 Gemini 服务端状态、重放工具或接入更新服务器；尤其不得用当前用户数据、凭据、真实外部动作、模型文件或应用本体更新自行验证这些目标。
- Git 只做本地可读逻辑提交，至少区分架构合同、协作与遥测、调度与扩展、DeepSeek 安全接入、Windows 验证交付；不上传、不改写既有基线、不报告提交标识。

- A/B 最小验证覆盖 Phase 1 回归、跨会话并行/取消、消息/委派/等待、Token 对账、应用运行时调度、Skill 渐进加载、插件执行边界、safeStorage 秘密边界、DeepSeek local fake 与 Windows 大/窄窗。
