- 旧 `sessions.json + events.ndjson + 其他 JSON/NDJSON` 在首次打开旧数据根时先创建本次迁移的一次性回滚副本，再可重复导入、验证关联并原子切换。失败时原格式保持权威且可再次尝试；成功后不把回滚副本包装成日常备份。

## 5. Checkpoint 2：单一 Runtime 所有者、同会话并行与崩溃恢复

### 5.1 Runtime host

- 当前用户、当前 data root 只允许一个 Runtime 所有者。Windows 使用受限到当前用户/明确 data root 的 named pipe 或等价本机 IPC；桌面已拥有 Runtime 时 CLI 连接它，桌面未运行时 CLI 可启动无界面 Runtime。
- 客户端订阅同一 session/run/token/schedule/extension snapshot 和 canonical event；断线可重连并从 revision 补齐。所有权交接先停收新任务、处理活动 run、释放写者后再接管，不允许双写窗口。
- 电脑完全访问在所有者退出、崩溃或交接时失效；受信任项目权限按既有持久合同保留。

### 5.2 多 run 与容量

- runId 成为并发状态的 canonical key；同一会话可同时有手动、委派和自动 run，消息、上下文、事件、取消和工具结果互不串线。
- 全局并发默认 3，可在高级设置调为 1–8；桌面、CLI、调度、本地推理共用名额。只有容量或真实资源锁冲突才排队，柔性优先级随等待提升但不抢占活动 run。
- UI 显示同会话 run stack；取消只作用于目标 run。CLI 可列出/选择/取消具体 run，不再把 sessionId 当唯一活动执行。

### 5.3 崩溃恢复

- Provider 请求、工具批准、工具开始/完成、产物落盘和审查/提交均写明确 checkpoint。
- 明确成功步骤不重跑；结果未知的 Provider/工具步骤按 ADR-0042 自动重放并生成可见 `may_repeat` 回执；需要电脑完全访问的步骤改为等待重新授权。
- 恢复失败保持现场和诊断，不伪装完成、不死循环重放。

### 5.4 门

- 桌面所有者+CLI 客户端、CLI 所有者+桌面客户端、重连、交接、双写拒绝、同会话至少两个无冲突 run 实际重叠、同资源串行、容量 1/3/8、取消隔离、崩溃三类 checkpoint 恢复。
- 159 项及新增 Runtime/IPC/recovery/multi-run 测试全绿；无第二 Runtime 装配。

## 6. Checkpoint 3：会话生命周期、模型路由、长期记忆、压缩与项目索引

### 6.1 会话与路由

- 会话永久保留直至明确删除；提供搜索、项目/provider/status 筛选、固定、明确删除与大列表虚拟滚动，不能自动归档或隐藏。
- 会话固定模型保持默认；智能分配默认关闭，开启后为质量优先/均衡/轻量优先。只在尚未开始的委派/子任务选择候选，显示原因、能力与缓存影响；run 开始后冻结 provider/profile/model/reasoning，失败不静默换模。

### 6.2 记忆与压缩

- 会话记忆自动、项目记忆只在同项目注入、个人记忆必须用户明确保存。每条有来源、作用域、创建/使用时间，可查看、编辑、停用、删除。
- 默认 90 天或事实冲突时标记“可能过时”并停止自动注入，集中提醒；软容量只提醒，不阻断保存、不自动删除。
- 上下文接近 profile 阈值时生成不可变摘要 generation，只替换后续 Provider 的较早上下文；原始会话永远保留，摘要 usage/cache 独立记录。摘要失败继续使用可容纳的原始上下文并明确状态。

### 6.3 项目索引

- 只对用户明确打开的项目建立路径/词法/符号增量索引，不扫描整机。索引过期、关闭或失败时在同一项目内实时补查并标来源。
- 每项目可选完全本地语义索引；没有本地语义能力时保持关闭，不调用云端 embedding。
- 索引低优先级运行；Agent、构建、本地推理或资源压力时降速/暂停，从 checkpoint 恢复。项目外路径、秘密文件和忽略目录不入索引。

### 6.4 门

- 10,000 条会话 fixture 的搜索/筛选/虚拟列表、删除确认；固定/智能三档的透明冻结和零静默换模；三层记忆 CRUD/过时/容量/注入；压缩保留原历史；增量/删除/重命名/过期/实时 fallback/暂停恢复/零全盘扫描。
- 桌面和 CLI 均有同源消费者；159 项及新增测试全绿。

## 7. Checkpoint 4：完整调度、统一工具输出、通知与保留策略

- 调度只在桌面或显式 CLI Runtime 存活时运行，不安装服务或 Windows 计划任务。暂停/删除/恢复、权限等待、项目失效和导入时区均有可见状态。
